Operating On Data in Pandas#

A. ufuncs in Pandas#

Since Pandas is designed to work with NumPy, all the ufuncs of NumPy will also work on the Pandas Series and DataFrame objects.

# import the libraries 
import pandas as pd
import numpy as np

🔹 What are ufuncs in NumPy?#

  • ufunc stands for “Universal Function”.

  • They are vectorized functions that operate element-wise on ndarray objects in NumPy.

  • Written in C for efficiency, they are much faster than Python loops.

Think of them as functions that automatically loop over arrays, element by element, without you writing explicit loops.

🔹 Example#

import numpy as np

# Regular Python list addition (slow)
a = [1, 2, 3, 4]
b = [5, 6, 7, 8]
result = [x + y for x, y in zip(a, b)]  
print(result)   # [6, 8, 10, 12]

# Using NumPy ufunc (fast)
arr1 = np.array(a)
arr2 = np.array(b)
result = np.add(arr1, arr2)
print(result)   # [ 6  8 10 12 ]

Here, np.add is a ufunc. It performs element-wise addition efficiently.

🔹 Key Features of ufuncs#

  1. Element-wise operations → Apply on each element automatically. Example: np.sqrt([1, 4, 9]) → [1., 2., 3.]

  2. Broadcasting support → Works on arrays of different shapes (if compatible).

    np.add([1, 2, 3], 10)   # [11 12 13]

  3. Optional output parameter (out) → Store result in an existing array.

    x = np.array([1, 2, 3])
y = np.array([10, 20, 30])
np.multiply(x, y, out=y)
print(y)   # [10 40 90]

  4. Vectorized → Faster than Python loops.

🔹 Types of ufuncs#

NumPy provides a huge set of built-in ufuncs:

  • Arithmetic: np.add, np.subtract, np.multiply, np.divide, np.power

  • Comparison: np.greater, np.less, np.equal

  • Logical: np.logical_and, np.logical_or

  • Trigonometric: np.sin, np.cos, np.tan

  • Exponential & Log: np.exp, np.log, np.log10

  • Rounding: np.floor, np.ceil, np.round

✅ In short: Ufuncs are fast, element-wise, vectorized functions in NumPy that replace the need for explicit Python loops.

B. Ufuncs: Index Alignment#

B.1 Index Alignment in Series#

# Dictionary for GDP of states (in millions of dollars)
gdp = pd.Series({'California': 3134962, 'Texas': 1852682, 'New York': 1766405}, name='gdp')

# Dictionary for population
population = pd.Series({'California': 97, 'Texas': 41, 'Florida': 155}, name='population_density')

print(gdp)
print(population)

# let us calculate gdp per capita 
print(gdp/population)

B.3 Index Alignment in DataFrame objects#

# DataFrame for area (in square kilometers)
area1_df = pd.DataFrame({'Area (km^2)': [423967, 695662, 170312]},
                       index=['California', 'Texas', 'Florida'])

# DataFrame for population density (people per square kilometer)
area2_df = pd.DataFrame({'Area (km^2)': [423967, 695662, 180312]},
                          index=['California', 'Texas', 'New York'])

area1_df.add(area2_df)
Area (km^2)
California 847934.0

So, for a DataFrame, the alignment takes place for both the column and the row indices!

C. Ufuncs: Operations between DataFrame and Series#

Here, too the alignment is maintained too!

Also the operations follow the broadcasting rules of NumPy

rng = np.random.default_rng(10)

df = pd.DataFrame(rng.integers(50, size=(4,4)), columns=['A','B','C','D'])
print(df)

print(f'The df after subtracting the first row is: \n{df-df.iloc[0,]}')

print(f'The df after subtracting the first column: \n{df.subtract(df["A"], axis=0)}') # axis is 0 since we subtract each column along the horizontal axis
