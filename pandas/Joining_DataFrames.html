Similarly, I can also concatenate two dataframes into one.

NOTE

  • Pandas concatenation preserves indices, even if the result will have duplicate indices!

  • If you’d like to simply verify that the indices in the result of pd.concat do not overlap, you can include the verify_integrity flag. With this set to True, the concatenation will raise an exception if there are duplicate indices.

name_age_reduced = pd.concat([
    titanic_name[:5],
    titanic_age[:5]

  • Ignoring the index during concatenation

store_a = pd.DataFrame({
    'Product': ['Pen', 'Pencil'],
    'Sales': [100, 150]
})

store_b = pd.DataFrame({
    'Product': ['Notebook', 'Eraser'],
    'Sales': [200, 80]
})

pd.concat([store_a, store_b], axis=0, ignore_index=True)
Product Sales
0 Pen 100
1 Pencil 150
2 Notebook 200
3 Eraser 80

  • Using keys for Hierarchical Indexing

pd.concat([store_a, store_b], keys=['Store A', 'Store B'])
Product Sales
Store A 0 Pen 100
1 Pencil 150
Store B 0 Notebook 200
1 Eraser 80

  • Inner Join on Columns

store_c = pd.DataFrame({
    'Product': ['Marker'],
    'Discount': [10]
})

pd.concat([store_a, store_c], join='inner', ignore_index=True)
Product
0 Pen
1 Pencil
2 Marker

df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Score': [85, 90, 95]
})
df.set_index('Name')
